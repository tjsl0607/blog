어느 날 Lighthouse 점수가 눈에 띄게 떨어진 걸 발견했습니다. 원인을 찾아보니 초기 번들이 1MB를 넘어가고 있었어요.

## 먼저 측정하기

감으로 최적화하면 헛수고를 하기 쉽습니다. 번들 분석 도구로 무엇이 얼마나 차지하는지부터 확인했어요.

```bash
npx vite-bundle-visualizer
```

## 효과가 컸던 것들

1. 날짜 라이브러리를 가벼운 대안으로 교체
2. 차트 컴포넌트를 동적 import로 분리
3. 아이콘을 개별 import로 변경

| 작업 | 감소량 |
| --- | --- |
| 날짜 라이브러리 교체 | 약 70KB |
| 차트 동적 import | 약 180KB |
| 아이콘 개별 import | 약 45KB |

## 정리

가장 큰 교훈은 **측정 없이는 최적화도 없다**는 것이었습니다.
